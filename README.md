# قارئ الفصول 1.3

قارئ روايات عربي يعمل محليًا على أندرويد. المكتبة تبدأ ببطاقات الروايات وأغلفتها، وداخل كل رواية تظهر فصولها. تبقى تبويبات «المكتبة»، «متابعة»، و«الإعدادات» كما هي.

## الجديد

- إنشاء الروايات وتعديلها وإضافة صورة غلاف من الهاتف.
- تحديد عدة روايات أو فصول بالضغط المطوّل، ونقلها إلى السلة مع التراجع والاسترجاع.
- استقبال النص المحدّد أو ملفات TXT/MD/HTML عبر مشاركة أندرويد، ثم تحريره واختيار الرواية ومعاينة التقسيم قبل الحفظ.
- تقسيم بالعناوين أو بفاصل يدوي، مع الحفاظ على المقدمة والنص.
- حفظ مسودات الإضافة واستقبال حتى خمس مشاركات متتالية دون استبدال المسودة السابقة.
- إبقاء تقدم الفصل دون إحصاءات الكلمات أو وقت القراءة.

للنقل من ChatGPT أو Gemini، شارك **نص الترجمة** أو ملفًا نصيًا. مشاركة رابط المحادثة وحده لا تنقل محتواها. لا يوجد تسجيل دخول إلى هذه الخدمات أو مزامنة للمحادثات أو حاجة إلى مفتاح API لهذه الميزة.

## الحفاظ على البيانات

معرّف التطبيق ما زال `com.aistudio.chapterreader.qrfslx`، وقاعدة البيانات `chapter_reader_offline.db`. ترقية قاعدة البيانات من الإصدار 1 إلى 2 تضيف دعم الأغلفة وسجل الاستيراد دون حذف البيانات. تُستعاد النسخ الاحتياطية القديمة، ويشمل التصدير الجديد صور الأغلفة.

تثبيت APK فوق النسخة الحالية يتطلب **مفتاح توقيعها نفسه**. لا تحذف التطبيق عند تعارض التوقيع. احفظ نسخة احتياطية قبل التحديث. [دليل التحديث والتوقيع](UPDATE-1.3.md) يشرح الخيارات والقيود.

## البناء

المتطلبات: Java 21، Gradle 9.3.1، Android SDK 36.1، وBuild Tools 36.0.0.

```sh
gradle testDebugUnitTest lintRelease assembleRelease -PunsignedBuild=true --no-daemon
```

ينتج هذا الأمر APK غير موقّع للفحص، يحتاج توقيعًا قبل التثبيت. يشغّل GitHub Actions الاختبارات والبناء تلقائيًا. عند إعداد أسرار `APP_KEYSTORE_BASE64` و`STORE_PASSWORD` و`KEY_ALIAS` و`KEY_PASSWORD` الاختياري، يظهر APK موقّع في Artifacts. لا يُنشأ مفتاح عشوائي بديل عند غياب المفتاح.

## الأداء والتحقق

تُعرض القوائم عند الحاجة، وتُحمّل بيانات الفصول الوصفية دون نصوصها الكاملة. تُصغّر الأغلفة في الخلفية وتُخزّن مؤقتًا بحد ذاكرة ثابت. تبقى عمليات استيراد النصوص والنسخ الاحتياطية خارج مسار عرض الواجهة.

تغطي الاختبارات ترقية قاعدة البيانات، محتوى الفصول ومواضع القراءة، التحديد والحذف والتراجع، النسخ الاحتياطية والأغلفة، المشاركة والمسودات وتقسيم النص. لم يُقَس الأداء على Samsung M02s فعلي.
