# قارئ الفصول 1.2

تحديث لتطبيق أندرويد الأصلي. ثلاثة تبويبات: المكتبة، متابعة، والإعدادات. تبقى بيانات الروايات والفصول والقاموس والملاحظات محليًا على الهاتف.

## التغييرات

- إزالة شاشة الإحصائيات وعدّادات الكلمات وأوقات القراءة والتعلّم التلقائي للسرعة.
- إبقاء نسبة تقدم الفصل وعدد الفصول المقروءة فقط.
- قائمة واحدة لأدوات المكتبة، بطاقات أقصر، وترتيب إعدادات النسخ الاحتياطي قبل تنسيق الخط.
- عرض الفقرات والبطاقات عند الحاجة، تقسيم النص والبحث في الخلفية، وتقليل عمليات الحفظ أثناء التمرير.
- إصلاح الانتقال بين الفصول وأزرار الصوت وحفظ الموضع داخل الفقرة.
- تحديد ذاكرة التراجع في المحرر، وحفظ التعديلات عند الخروج، وتجنّب الكتابة في التخزين مع كل حركة لشريط الإعدادات.
- إصلاح استعادة الملاحظات وحفظ هويات السجلات والمحذوفات في النسخ الاحتياطية. يتم التحقق من النسخة كاملة قبل تعديل قاعدة البيانات.

## تثبيت التحديث دون فقد البيانات

هوية الحزمة ما زالت `com.aistudio.chapterreader.qrfslx`، واسم قاعدة البيانات `chapter_reader_offline.db` وإصدارها `1`. لم تتغير الجداول أو مفاتيح الإعدادات الحالية. لا توجد هجرة تمسح البيانات.

يجب توقيع APK **بمفتاح النسخة المثبتة نفسه**. المفتاح غير مرفق بالمشروع ولا يمكن استخراجه من APK. لا تنشئ مفتاحًا بديلًا إذا كان هدفك تثبيت تحديث فوق النسخة القديمة. لا تحذف التطبيق الحالي عند ظهور تعارض توقيع. احفظ نسخة احتياطية من النسخة الحالية قبل التحديث.

## GitHub

بعد إدخال ملفات المشروع إلى المستودع، يبني GitHub Actions التحديث مع كل دفع إلى `main` أو `master`. لم يعد ينشئ مفتاحًا عشوائيًا عند كل بناء.

أضف مفتاح **التطبيق الحالي** ضمن GitHub Actions Secrets، بإحدى طريقتين:

1. `APP_KEYSTORE_BASE64` مع `STORE_PASSWORD` و`KEY_PASSWORD` و`KEY_ALIAS` للمفتاح الأصلي.
2. `ANDROID_DEBUG_KEYSTORE_BASE64` إذا كانت النسخة الحالية موقعة بمفتاح debug الأصلي، بكلمات مروره واسم alias القياسية.

المتغير الاختياري `EXPECTED_CERT_SHA256` يتحقق من بصمة شهادة النسخة الحالية قبل النشر. لا ترفع ملف المفتاح نفسه إلى المستودع أو المحادثة.

عند غياب المفتاح ينجح الفحص إن لم توجد أخطاء، لكن لا ينشر APK موقّعًا. بعد توافر المفتاح يظهر APK في Artifacts؛ وعلى الفرع الرئيسي يُنشر في Releases تلقائيًا.

## البناء والتحقق

المتطلبات: JDK 17 أو 21، Gradle 9.3.1، Android SDK 36.1، وBuild Tools 36.0.0.

```sh
gradle testDebugUnitTest lintRelease assembleRelease -PunsignedBuild=true
```

هذه العملية تبني ملفًا غير موقّع للفحص، ولا يكون جاهزًا للتثبيت قبل توقيعه بالمفتاح الأصلي.

اختبارات حماية البيانات موجودة في `app/src/test/java/com/example/data/UpdateSafetyTest.kt`. تشمل استعادة النسخ القديمة والملاحظات، رفض النسخ التالفة قبل الكتابة، عدم تحميل أجسام الفصول في قائمة المكتبة، وحفظ الموضع دون المساس بالنص أو المفضلة.

التحسينات تستهدف تقليل العمل على معالج الهاتف وذاكرته. لم يُقَس الأداء على جهاز Samsung M02s فعلي، ولا توجد دعوى بمعدل إطارات أو نسبة تسارع مقاسة.
